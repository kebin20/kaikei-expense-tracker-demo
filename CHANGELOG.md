# Demo release history

## V3.10.4

Weekly estimate cards show the selected month's ranges: 1–7, 8–15, 16–23 and 24 through month-end. Leap years, 30-day months, renamed/emoji categories and accessible card descriptions are supported. The guide and date-based week selection match these cutoffs; stored categories and fictional transaction amounts are unchanged. The private V3.10.3 startup-specific changes are not part of this demo-only label update.

## V3.10.2

Includes the queued-placeholder identity merge and matching modal-footer fix alongside the V3.10.1 demo refresh below.

## V3.10.1

Aligned the client UI with Kaikei V3.10.1: daily groups, filters, estimates, recovery tools, PWA caching and responsive layouts. Persistence remains browser-local. Private Sheet/server/native features are excluded.

## V3.4

Added a local full-bill editor deducting fixed costs except rent.

## V3.3
